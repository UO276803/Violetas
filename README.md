# Floristería Violeta

Pequeña experiencia web interactiva para móvil, hecha con HTML, CSS y JavaScript puro.

## Probar en local
1. Descomprime la carpeta.
2. Abre `index.html` en el navegador (o usa Live Server en VS Code).

## Publicar en GitHub Pages
1. Sube `index.html`, `style.css` y `script.js` a la raíz de un repositorio.
2. En GitHub entra en Settings → Pages.
3. En Build and deployment selecciona Deploy from a branch.
4. Selecciona `main` y `/ (root)`, guarda y espera a que GitHub genere el enlace.

## Personalización rápida
- Texto final: busca `Unas violetas para alegrarte el día` en `index.html`.
- Firma: busca `Con cariño, desde Asturias.` en `index.html`.
- Fecha: busca `9 DE NOVIEMBRE` en `index.html`.
- Colores y diseño: modifica las variables al principio de `style.css`.

La tipografía se carga desde Google Fonts; si no hay conexión, se usarán fuentes de respaldo.
